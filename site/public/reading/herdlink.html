Structure, geography and time

I built HerdLink to examine network structure alongside geography. Switching views keeps the selected nodes in focus, making it easier to see how trade connections relate to distance and regional boundaries.

  • Network and map views: compare connectivity with geographic position.
  • Focus mode: inspect one node or region and its trading partners.
  • Time controls: step through snapshots or replay changes.

Keyboard shortcuts

  • M Toggle Map / Graph
  • Q Exit focus mode
  • ↑ / ↓ Switch focal nodes
  • ← / → Step through time (when time controls are available)
  • Space Play / pause time replay
  • F Jump back to the start
  • R Restore links (after filtering/highlighting)
  • S Export a screenshot
  • H Toggle the help overlay
